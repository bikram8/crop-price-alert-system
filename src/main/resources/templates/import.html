Import price data

Every row is cleaned before saving: crop names are unified, bad dates and impossible prices are skipped, and re-importing the same day updates rows instead of duplicating them.

1. Upload a CSV

Use the CSV from data.gov.in ("Current Daily Price of Various Commodities from Various Markets") or any file with columns State, District, Market, Commodity, Arrival_Date, Min_Price, Max_Price, Modal_Price.

For a demo, download a ready-made next-day bulletin (tomato prices are up about 30% in it, so tomato alerts will fire) and upload it here.

Daily automatic import: off (set mandi.api.scheduled=true)

How the data flows

  1. Rows come in from CSV or the API
  2. Each row is validated and the crop name normalised
  3. New mandis/crops are created on first sight
  4. Prices are saved (one row per mandi, crop and day)
  5. After saving, an event triggers the alert check
  6. Matching farmers get an SMS
